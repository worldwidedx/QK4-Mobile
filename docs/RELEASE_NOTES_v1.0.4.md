# QK4 Mobile v1.0.4

QK4 Mobile v1.0.4 adds extensive support for the CTR2-MIDI controller, new
straight-key options, and portable controller and function-key settings.

## CTR2-MIDI control

- Connect a CTR2-MIDI controller by USB or Bluetooth LE from its own dedicated
  **CTR2** setup page.
- Use the CTR2 at the same time as a separate TinyMIDI, HaliKey MIDI, or custom
  MIDI device connected through the CW Keyer page.
- Start with a ready-to-use K4-Control-style mapping, then customize all eight
  knob modes and every button.
- Assign different actions to short and long button presses.
- Control frequently used radio functions including VFO A and B, volume,
  filters, NR, NB, RIT/XIT, squelch, RF power, CW speed, and panadapter zoom.
- Mapped controls interact with the QK4 Mobile interface, not just the radio:
  when possible, pressing a button opens the corresponding on-screen control
  and shows visible feedback for the selected action.
- Use the knob like a radio multifunction control: press a mapped button to
  open and select an adjustment such as NR, NB, filter bandwidth, or RIT/XIT,
  then turn the knob while watching the setting change on screen.
- Assign buttons to built-in actions such as TX/RX, Rate, KHZ, and band changes,
  or enter supported K4 Programmer's Reference commands and command sequences.
- Choose the normal or extended CTR2 button layout.

## Portable controller settings

- Save a complete CTR2 setup to a user-accessible mapping file on the phone
  and load it again later.
- Copy CTR2 mapping files from the phone to a PC, edit or share their
  documented, human-readable contents, copy them back to the phone, and load
  them into QK4 Mobile.
- Save and load complete F1-F8 function-key configurations, including both
  button labels and K4 commands. These files can also be copied to a PC,
  edited, shared, and copied back to the phone.
- Receive a prompt before leaving a setup page or replacing a configuration
  when there are unsaved changes.

## Straight-key and external-keyer support

- Use a straight key or external keyer with TinyMIDI, HaliKey MIDI, a learnable
  custom MIDI device, or CTR2-MIDI.
- Hear a locally generated sidetone while using a straight key or external
  keyer.
- Continue using the established Iambic paddle setup with its orientation,
  mode, weight, CW speed, sidetone, and paddle-test controls.
- Use two connected MIDI devices as CW inputs without one device interfering
  with the other.

## Improved CTR2 operation

- Tune either VFO in the expected direction using that VFO's selected tuning
  step.
- Make smooth, fine adjustments to radio controls and CW speed.
- Zoom across the full panadapter range while keeping the tuned signal in
  place.
- Disconnect and reconnect USB or Bluetooth MIDI devices without restarting
  QK4 Mobile.
